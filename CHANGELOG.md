# Changelog

All notable changes are documented in this file. The project follows Semantic Versioning once a stable public release is established.

## [Unreleased]

### Planned

- Real-time Web PubSub transport.
- Blob-backed APK artifacts and multi-instance state coordination.

## [0.3.0] - 2026-08-03

### Added

- One-use SDK handoff exchange with separate build-scoped telemetry credentials.
- Azure Blob session snapshots and automatic active-session restoration.
- Restoration of recent diagnostic timelines from Azure Table Storage.
- Authenticated screenshot and recording upload/download endpoints.
- Attachment events and protected dashboard viewing.
- Session-persistence health counters.

## [0.2.0] - 2026-08-03

### Added

- Structured diagnostic batch and Android installation-result endpoints.
- Crash, ANR, performance, and installation issue fingerprinting and grouping.
- Azure Table Storage archival through the web app managed identity.
- Application Insights and Log Analytics infrastructure.
- Professional issue dashboard, device context, metrics, stack traces, and live timeline.
- Server-side credential-pattern redaction and bounded diagnostic ingestion.

## [0.1.0] - 2026-08-03

### Added

- Secure QR session creation and device pairing.
- Named project/app metadata and remote APK publishing.
- Upload progress, APK validation, SHA-256 hashing, and one-use downloads.
- Device events and tester feedback endpoints.
- Azure App Service and Storage Account infrastructure templates.
- Linux-safe packaging and deployment automation.
